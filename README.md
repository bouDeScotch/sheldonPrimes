# sheldonPrimes
Attempting to find the next Sheldon Prime.

## What is a Sheldon Prime?

In the 73rd episode of *The Big Bang Theory*, Sheldon explains why 73 is a unique number: not only is it prime (the 21st prime number), but its reverse (37) is also prime, and surprisingly the 12th prime number (which is the reverse of 21).

## Background

The Sheldon primes are already listed on the OEIS [here](https://oeis.org/A393322), or for a simpler description, [here](https://oeis.org/A069469).

Before my research, and probably still at the time you're reading this, it was known that `a(10) > 10^9`. This was, at least as listed on the OEIS, the lower bound for the next Sheldon Prime if another exists (which is likely but unproven).

Using the C code in this repository and running the program for over 27 hours, I managed using brute force to find a new lower bound, proving that if a(10) exists, then `a(10) > 10^10`.

## How to run

Clone the repository to your computer, then run the following commands in your terminal from the folder containing the C file:

```sh
gcc -O3 -march=native -fopenmp -o prime_reverse prime_reverse.c -lm
./prime_reverse
```

## ⚠️ Hardware Warning:
Note that the program creates a ~35GB binary file storing a sieve up to the 10^10-th prime, and that as written above, it takes hours to run even with a good CPU (tested on a laptop i9-12900K). The main bottleneck is actually the SSD speed; you probably shouldn't even try to run this on an HDD.

Given the absurd amount of time required to run the search, I have also uploaded the hits.txt file generated by the program, which contains all the verified hits.
